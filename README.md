Este repositorio contiene los proyectos desarrollados durante el curso **Programación de Dispositivos Móviles** de la **Universidad Anáhuac**, enfocados en el desarrollo de aplicaciones móviles con **Flutter** y **Android Studio**.

> 📌 *Nota: Este repositorio es parte del material académico del curso y está diseñado como apoyo para los estudiantes.*

---

## 🎯 Objetivo del Curso  
Desarrollar habilidades en la creación de aplicaciones móviles multiplataforma (iOS y Android) utilizando Flutter, desde la concepción hasta la publicación, con énfasis en buenas prácticas de programación, diseño centrado en el usuario y trabajo colaborativo.

## 👨‍🏫 Instrucciones para Estudiantes

1. **Clona este repositorio**  
   ```bash
   git clone https://github.com/tu-usuario/nombre-repositorio-flutter-anahuac.git
   cd nombre-repositorio-flutter-anahuac
   ```

2. **Abre cada proyecto en Android Studio**
   - Ve a `File > Open` y selecciona la carpeta del proyecto (ej. `01_hola_mundo`)
   - Asegúrate de tener Flutter y Dart instalados.

3. **Ejecuta la app**
   ```bash
   flutter pub get
   flutter run
   ```

4. **Modifica y experimenta**  
   Usa los proyectos como base para practicar cambios, mejorar el diseño o añadir funcionalidades.

## 📝 Normas de Contribución (para el curso)
- ✅ Usa nombres descriptivos en variables, funciones y carpetas.
- ✅ Comenta tu código de forma clara y útil.
- ✅ No subas archivos de `build/`, `.dart_tool/` ni `android/app/.cxx/`.
- ✅ Mantén una estructura consistente (sigue la convención de nombres `XX_nombre_proyecto`).
- ❌ **No compartas claves API o información sensible.**
